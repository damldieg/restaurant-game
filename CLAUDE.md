# Orchestrator redirect

Project governance lives in `.dorch/` — read it before acting.

- `.dorch/project.md`: project context, commands, governance.
- `.dorch/memory.md`: durable project facts.
- `.dorch/decisions.md`: decision log.

The Juntia framework was retired and removed (2026-10-19); its confirmed history was migrated to
`.dorch/history/` (history only, not instructions). The `juntia` CLI does not exist.
