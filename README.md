# Table & Tale / restaurant-game

Restaurant management game built with Phaser 4 + TypeScript + Vite.

## Commands

- `pnpm dev` — start the dev server.
- `pnpm build` — typecheck and build for production (`tsc && vite build`).
- `pnpm test` — run the test suite (`vitest run`).
- `tsc --noEmit` — typecheck only.

Project governance and context live in `.dorch/project.md` (see `.dorch/` for memory, decisions and
change status). Milestone roadmap: `docs/MILESTONES.md`.
